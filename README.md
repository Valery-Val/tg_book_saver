# Telegram Audiobooks ETL Pipeline

Автоматизированный ETL-пайплайн для сбора, скачивания и каталогизации аудиокниг из Telegram-каналов. Проект реализует принципы Data Lake, идемпотентности и отказоустойчивости.

## Возможности

- **Разделение Extract и Load**: Сначала быстро сканируется канал и собираются метаданные, затем параллельно скачиваются файлы.
- **Идемпотентность**: Пайплайн можно перезапускать бесконечно. Он не будет скачивать уже загруженные главы и не сломает базу данных.
- **Отказоустойчивость**: Автоматические retry, обработка `FloodWait` от Telegram, сохранение статусов `failed` в БД.
- **Аналитика из коробки**: Все метаданные хранятся в DuckDB, что позволяет делать SQL-запросы по загруженным книгам.
- **Оркестрация**: Использование Prefect для мониторинга, логирования и управления задачами.

## Архитектура пайплайна

1. **Extract (`extractor.py`)**: Асинхронно итерирует сообщения в Telegram-канале. Определяет обложки книг (фото + текст) и аудиофайлы. Не скачивает медиа, а только формирует `ChapterMetadata`.
2. **Storage / State (`database.py`)**: Инициализирует DuckDB. Хранит агрегированную информацию о книгах (`books`) и детальную по главам (`chapters`). Реализует UPSERT для идемпотентности.
3. **Transform & Load (`processor.py`)**: Prefect-таска, которая параллельно (с ограничением через `Semaphore`) скачивает аудио, сохраняет в файловую систему и обновляет метаданные в DuckDB.
4. **Orchestration (`pipeline.py`)**: Prefect-флоу, которое связывает все этапы в единый процесс.
5. **Analytics (`analytics.py`)**: Готовый набор запросов к БД для проверки актуального состояния библиотеки.

## Технологический стек

| Технология | Назначение |
|---|---|
| **Telethon** | Асинхронный клиент для Telegram API |
| **Prefect** | Оркестрация workflow, retry, UI мониторинга |
| **DuckDB** | In-process OLAP база для хранения метаданных |
| **Pydantic / pydantic-settings** | Валидация и управление конфигурацией |
| **asyncio** | Асинхронное выполнение и контроль конкурентности |

## Установка и настройка

### Клонирование и зависимости

```bash
git clone https://github.com/Valery-Val/tg_book_saver.git
cd tg_book_saver

# Создаем и активируем виртуальное окружение
python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate

# Установка основных зависимостей
pip install .

# Опционально! Установка dev-зависимостей (ruff для линтинга, ipykernel для Jupyter)
pip install -e ".[dev]"
```
### Получение Telegram API credentials
Перейдите на my.telegram.org.<br>
Авторизуйтесь по номеру телефона.<br>
Перейдите в API development tools и создайте приложение.<br>
Скопируйте api_id и api_hash.

### Конфигурация
Создайте файл `.env` в корне проекта на основе `.env.example`

### Запуск
**Базовый запуск:**
```bash
python -m src.pipeline
```

**Запуск через Prefect (с UI):**
1. Запустите локальный сервер Prefect:
```bash
prefect server start
```
2. Откройте UI в браузере: http://127.0.0.1:4200
3. Запустите флоу:
```bash
python -m src.pipeline
```
Вы увидите выполнение задач, логи и статусы в реальном времени в веб-интерфейсе.

### Ограничение для тестов
Чтобы скачать только первые N книг, измените параметр в `pipeline.py`:
```python
asyncio.run(run_etl(max_books=2))
```
